# Linux Installation — mcpvectordb

Native Linux setup without Docker. Linux counterpart of [windows-setup.md](./windows-setup.md)
and [chatgpt-windows-setup.md](./chatgpt-windows-setup.md). Three options:

| Option                        | Client                            | Script                           |
| ----------------------------- | --------------------------------- | -------------------------------- |
| A — Python + uv (stdio)       | Claude Desktop, Claude Code       | `scripts/setup-linux.sh`         |
| B — Standalone binary (stdio) | Claude Desktop, Claude Code       | `scripts/build-linux.sh`         |
| C — Background service (HTTP) | ChatGPT, any URL-based MCP client | `scripts/setup-chatgpt-linux.sh` |

For a container instead, see [Local Container Setup](../deploy/local/README.md).

## Requirements

- Linux x86_64 with glibc (Debian/Ubuntu, Fedora, Arch, …)
- [uv](https://docs.astral.sh/uv/): `curl -LsSf https://astral.sh/uv/install.sh | sh`
- Python **3.11–3.13**; uv downloads one automatically (3.14 has no ONNX Runtime wheel)
- Option C only: systemd, and [Tailscale](https://tailscale.com/download/linux) for HTTPS

No root is needed for any option.

---

## Option A — Python + uv

1. Run the bootstrapper from the project directory:

   ```bash
   ./scripts/setup-linux.sh
   ```

   It installs dependencies (`uv sync`), creates `~/.mcpvectordb/`, pre-downloads the
   embedding model, writes `.env`, and prints the client config.

2. Paste the printed JSON into `~/.config/Claude/claude_desktop_config.json`, or run the
   printed `claude mcp add` command for Claude Code.

3. Restart Claude Desktop.

The JSON uses the full path to `uv`: apps started from a desktop launcher do not see
`~/.local/bin` on `PATH`.

## Option B — Standalone binary

Builds one executable with the server, all dependencies, and the embedding model.
No Python is needed on the target machine.

1. Build (output: `dist/mcpvectordb`, roughly 1 GB):

   ```bash
   ./scripts/build-linux.sh
   ```

2. Copy `dist/mcpvectordb` to the target machine.

3. Use the printed config: `"command"` is the binary path, `"args"` is empty.

The binary links against the build machine's glibc. Build on the oldest distribution
you want to run it on.

## Option C — Background service for ChatGPT

ChatGPT connects to MCP servers by HTTPS URL only, so the server must run permanently.
The script installs a **systemd user service** (`mcpvectordb-chatgpt`) running the
`streamable-http` transport on `127.0.0.1:8000`.

1. Run the setup script (as your normal user, not with `sudo`):

   ```bash
   ./scripts/setup-chatgpt-linux.sh
   ```

   Override the port with `MCP_PORT=8123 ./scripts/setup-chatgpt-linux.sh`.

2. Expose the server over HTTPS on your tailnet:

   ```bash
   tailscale serve --bg http://127.0.0.1:8000
   ```

3. In ChatGPT open **Settings → Apps → Advanced settings → Developer mode** and add the
   printed URL, e.g. `https://myhost.tail1234.ts.net/mcp`.

4. Ask ChatGPT "List all libraries" to confirm the connection.

The server only accepts requests whose `Host` header is `localhost` or listed in
`ALLOWED_HOSTS`. The script detects your Tailscale hostname and sets it. If Tailscale is
missing when you run the script, re-run it with
`ALLOWED_HOSTS=<your-tailscale-hostname>`.

On this network transport `ingest_url` refuses URLs whose host resolves to a
private, loopback or link-local address, so a remote client cannot make the server
fetch internal pages. Set `ALLOW_PRIVATE_URLS=true` in `.env` to allow intranet URLs.

### Managing the service

```bash
systemctl --user status mcpvectordb-chatgpt
systemctl --user restart mcpvectordb-chatgpt    # after editing .env
journalctl --user -u mcpvectordb-chatgpt -f     # logs
```

The unit file is `~/.config/systemd/user/mcpvectordb-chatgpt.service`. Transport, host,
port and allowed hosts are set in the unit and override `.env`; all other settings
come from `.env`.

### Uninstall

```bash
./scripts/uninstall-chatgpt-linux.sh
```

The script removes the service and asks before it deletes `~/.mcpvectordb/`.

## Data Directory Layout

```
~/mcpvectordb/                 ← App code (git clone)
└── .env                       ← Generated by setup-linux.sh; optional overrides

~/.mcpvectordb/                ← Runtime data (config.py default on Linux)
├── lancedb/                   ← Vector database (LANCEDB_URI)
├── models/                    ← Embedding model cache (FASTEMBED_CACHE_PATH)
└── server.log                 ← Optional (set LOG_FILE)
```

## Common Issues

| Symptom                                     | Fix                                                                                |
| ------------------------------------------- | ---------------------------------------------------------------------------------- |
| `No systemd user session`                   | Log in directly (desktop or `ssh`), not through `su` or `sudo`, then re-run        |
| Service stops when you log out              | Run `sudo loginctl enable-linger $USER`                                            |
| ChatGPT gets HTTP 421 `Invalid Host header` | Re-run setup with `ALLOWED_HOSTS=<your-tailscale-hostname>`                        |
| `Port 8000 is already in use`               | Re-run with `MCP_PORT=<free port>`, and use that port in `tailscale serve`         |
| Claude Desktop shows no tools               | Use the full `uv` path in `"command"`; check the JSON is valid                     |
| Schema mismatch or Arrow error on ingest    | Unset `EMBEDDING_MODEL` / `EMBEDDING_DIMENSION` in your shell; let `.env` set them |
